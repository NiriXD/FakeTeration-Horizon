## 🚫 Why is the download on the Horizons page?
* **Official Project Ecosystem:** The release management system handles installation, updates, and environment setups automatically from that page.
* **Centralized Releases:** Keeping files in one location prevents outdated versions from circulating.
* **Clean Repository:** This space is kept lightweight solely to manage community feedback and fixes.

## 🐛 Bug Reports & Feature Requests
If you find a bug or have a suggestion, look through the existing issues first. If your problem isn't listed, open a new one.

### How to Submit an Issue:
* Check if someone already reported the issue.
* Use a clear, descriptive title.
* Describe exactly what happened and how to recreate it.
* Mention your system details if relevant.
